# 用户详情与后台编辑实现计划

> 执行方式：按已确认设计在当前工作区实施；后端由独立代理负责，前端与集成由主代理负责，完成后进行需求与代码 Review。

**目标：** 两类用户详情采用顶部身份摘要、右上角编辑、分区双列资料，在原详情中切换编辑；普通用户后台可直接修改联系方式。

**架构：** 共享 `src/ui/UserDetailsLayout.tsx` 负责资料布局，两类用户各自管理表单及 TanStack Query mutation。普通用户通过 `PUT /api/sys-user/users/{id}` 保存昵称、手机号、邮箱，后端保留用户本人验证码换绑流程。

**技术：** React、TypeScript、Less Modules、TanStack Query；Spring Boot、MyBatis、MySQL。

## 已确认设计

- 顶部头像、名字与 `用户ID：N`，名字后无状态；编辑位于右上角，切换为取消/保存。
- 基本信息不展示 ID，不增加用户类型；昵称单独占一行，输入框最大 260px。
- 标签统一中文冒号；普通用户手机号、邮箱同一行，管理员直接修改。
- 账号信息仅状态和创建时间，只读文本。系统用户保留现有独立启停、密码重置和头像上传能力。
- 删除只在列表操作，总数左下角 `共 N 个用户`；系统用户旧前新后排序保持。
