# Project Engineering Governance Skill

[English](README.md) | [简体中文](README.zh-CN.md)

Turn vibe-coded projects into maintainable, evidence-driven software.

A reusable engineering governance skill for AI coding agents, covering engineering rules, testing, CI gates, documentation governance, simplification, and agent knowledge continuity.

## Core Ideas

- Current Reality First
- Evidence-Driven Governance
- Coverage is a review signal, not a target
- Verification layers are a model, not a checklist
- One Fact, One Home
- Simplification is part of governance
