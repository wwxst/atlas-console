# 后端开发入口

执行本仓库的开发、构建、测试或环境排查前，先阅读并遵循：

- [后端工程规范](docs/engineering.md)：业务边界、最小实现原则、JDK、构建命令与现有测试能力。
- [AI Java 开发规范](docs/ai-java-development.md)：代码、测试与文档的编写要求。
- [后端质量门禁](docs/quality-gates.md)：审查顺序、测试触发条件、通过标准与交付记录。

每次后端代码修改完成后，按质量门禁依次执行 **4 次规范检查、3 次代码 Review**，修复确认的问题并完成适用的测试。最终修改部分必须有对应 Review 和验证；必需检查缺失或失败时，不能宣称通过门禁。

纯文档修改按门禁中的文档检查执行。JDK 的查找方式与命令行运行规则统一维护在工程规范中。
