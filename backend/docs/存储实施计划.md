# 本地与阿里云存储实施计划

目标：完成已确认的全局配置、OSS 空间绑定和统一头像存储，修复新数据库与系统用户代码的映射。

实现采用现有 Spring Boot 4、MyBatis、MySQL、React 和全局错误 Toast。只支持 `local`、`aliyun`。复用已改动的工作区，不提交、不迁移或重建业务库。远程文件操作在数据库事务外完成，账号引用使用短事务提交。

## 接口契约

所有管理接口使用 `/api/sys-user/storage` 前缀、admin 权限和现有 `Result` 响应。

| 方法与路径 | 请求 | 响应 data |
| --- | --- | --- |
| GET `/settings` | 无 | `{storageType: 'local'或'aliyun'}` |
| PUT `/settings` | `{storageType}` | 同上 |
| GET `/oss/credentials` | 无 | `{configured: boolean}`，不回传凭据 |
| PUT `/oss/credentials` | `{accessKeyId,accessKeySecret}`，均必填 | `{configured: true}` |
| GET `/spaces` | `page=1,pageSize=15`，最大100 | `PageResult<StorageSpaceVO>` |
| POST `/spaces` | `{bucketName,regionId,accessPermission}` | `StorageSpaceVO` |
| POST `/spaces/sync` | 无 | `{syncedCount: number}` |
| PUT `/spaces/{id}/default` | 无 | `StorageSpaceVO` |
| PATCH `/spaces/{id}/domain` | `{accessDomain: string或null}` | `StorageSpaceVO` |
| DELETE `/spaces/{id}` | 无 | 无 |

`StorageSpaceVO` 字段为 `id:number,bucketName,regionId,accessDomain:string或null,isDefault:boolean,createdAt,updatedAt`。公共 GET `/files/{id}` 返回本地图片或重定向 OSS HTTPS 图片；只开放 GET/HEAD，管理接口仍受保护。

## 文件服务内部契约

`com.web.project.storage.service.StorageService` 提供 `StorageFile storeAvatar(MultipartFile)`、`void delete(Long)` 与 `static String url(Long)`；`StorageFile` 为带 getter 的实体，至少包含 `id,provider,spaceId,storageKey,contentType,sizeBytes`。上传先校验真实内容、写入物理文件，再短事务记录元数据；记录失败清理物理文件。`delete(null)` 无操作；删除依照文件实际目的地，不依照全局设置。调用方仅在头像引用提交后删除旧文件。
