# PostgreSQL 演示数据导入

先创建空的 `web_project` PostgreSQL 数据库并启动后端，让 Flyway 自动创建业务表和默认配置；不要导入历史 MySQL 快照。确认应用已成功启动后，再运行 `import_demo_data.bat`，它只向现有表插入 50 个系统用户和 100 个普通用户，并运行 `03_verify.sql`。

PowerShell 示例：

```powershell
$env:PSQL_BIN = 'C:\Program Files\PostgreSQL\17\bin\psql.exe' # 可选
$env:DB_HOST = 'localhost'
$env:DB_PORT = '5432'
$env:DB_NAME = 'web_project'
$env:DB_USERNAME = 'atlas'
$env:DB_PASSWORD = '本地数据库密码'
.\demosql\import_demo_data.bat
```

脚本支持 `PSQL_BIN`、`DB_HOST`、`DB_PORT`、`DB_NAME`、`DB_USERNAME`、`DB_PASSWORD`。密码通过 `PGPASSWORD` 传给 psql，不写入命令行参数。两份演示 SQL 使用 `ON CONFLICT DO NOTHING`，可重复执行，不会覆盖已有记录。

仅在本地或隔离的演示数据库运行。回归测试需要安装 PostgreSQL 客户端，并使用有权创建/删除临时测试库的账号：

```powershell
$env:PSQL_BIN = 'C:\Program Files\PostgreSQL\17\bin\psql.exe'
python -X utf8 scripts/test_demo_import.py
```
